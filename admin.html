Cadastro / Edição de Produtos
Você pode selecionar mais de uma forma de venda. Lote permite informar quantas unidades existem em cada lote.
📋 Como funciona

1. Cadastre o produto informando nome e categoria.

2. Escolha as formas de venda que o cliente poderá selecionar.

3. Lote permite definir quantas unidades existem em cada lote.

4. Produto inativo permanece cadastrado, mas não aparece para o cliente.
